## 📖 Tentang

Repositori ini berisi website portofolio / online CV yang dibuat sebagai **tugas mata kuliah Pemrograman Web**. Halaman menampilkan profil, riwayat pendidikan, organisasi dan kepanitiaan, keahlian, proyek, serta kontak.

Seluruh halaman dibangun hanya dengan HTML dan CSS sebagai penerapan materi dasar struktur dokumen web, styling, dan layout — tanpa JavaScript maupun framework.

## ✨ Bagian Halaman

| Bagian | Isi |
|---|---|
| **Profil** | Foto, nama lengkap, program studi, dan deskripsi singkat |
| **Pendidikan & Pengalaman** | Riwayat pendidikan, organisasi, dan kepanitiaan |
| **Keahlian** | Hard skills, soft skills, dan pelatihan |
| **Proyek** | Quest-Log — aplikasi Android pencatat tugas |
| **Kontak** | Email, telepon, media sosial, dan formulir pesan |

## 🛠️ Teknologi & Konsep

- **HTML5** — struktur semantik (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3** — external stylesheet, selektor *element / class / id*, box model (margin, padding, border), tipografi, dan palet warna
- **Layout** — satu kolom dengan penyesuaian responsif lewat media query sederhana
- **GitHub Pages** — hosting situs statis
