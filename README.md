# Portofolio — Naufal Muttaqin

Website portofolio / online CV sederhana yang dibuat dengan **HTML dan CSS** (tanpa JavaScript atau framework) untuk tugas mata kuliah Pemrograman Web.

## Live

https://mtaqinnaufal.github.io/my-portofolio/

## Isi repositori

| File | Keterangan |
|---|---|
| `index.html` | Struktur halaman (profil, pendidikan, keahlian, kontak) |
| `style.css` | External stylesheet |
| `images/profile.png` | Foto profil |

## Deploy

Repo di-push ke GitHub lalu GitHub Pages diaktifkan (Settings → Pages → Deploy from a branch → `main` / root). URL live akan muncul setelah build selesai.
